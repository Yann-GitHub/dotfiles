## Setup Notes

The intention is to be able to run a setup script after cloning the repo on a Mac or Linux system and be up and running very quickly.

### Linux and MacOS

```bash
DOTFILES_DIR=$HOME/Repos/github.com/Yann-GitHub
mkdir -p $DOTFILES_DIR
cd $DOTFILES_DIR
git clone https://github.com/Yann-GitHub/dotfiles.git
cd dotfiles
```
